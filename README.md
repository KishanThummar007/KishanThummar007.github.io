# Kishan Thummar

I am interested in physics-based simulation, world models and trajectory optimization, and in using them to automate wire harness manufacturing and assembly in the automotive industry.

## Research

- **Trajectory Planning and Optimization for Automated Cable Harness Installation using Multi-Gripper Systems**
  IEEE International Conference on Industrial Engineering and Engineering Management (IEEM 2026)
- **WireHarness-MultiGripper-RL**: a Gymnasium environment for multi-gripper wire harness picking in MuJoCo, listed in the Farama Gymnasium third-party environments
